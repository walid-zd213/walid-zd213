## نبذة

أنا مطوّر مستقل وباحث تقني أركز على بناء أنظمة ذكية وعملية ومفتوحة.

يدور اهتمامي حول الأتمتة، والبرمجيات القائمة على الوكلاء، والبنية ذاتية الاستضافة، والتجارب المفتوحة المصدر.

أهتم بتحويل الأفكار المعقدة إلى أدوات موثوقة، وسير عمل قابلة لإعادة الاستخدام، وأنظمة تقنية سهلة الفهم.
